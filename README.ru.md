# Inside Bosch · версия 0.3

![Inside Bosch — Сад тайн](docs/portfolio/assets/cover.png)

**[Читать дизайнерский кейс →](docs/portfolio/CASE_STUDY.ru.md)** · [English case](docs/portfolio/CASE_STUDY.md)

Интерактивное исследование «Сада земных наслаждений» Иеронима Босха. Концепция и продуктовое направление — Альбина Урубкина; реализация выполнена с помощью ИИ.

В новой версии: светлый разворот художественного каталога, Cormorant Garamond и Manrope, тёмное пространство картины, спокойная панель объяснений, маленькая метка выбранной детали. Пояснения раскрываются по запросу; повторное изображение из боковой панели убрано.

Для портфолио подготовлены выразительная обложка, иллюстрации из подлинной картины, описание решений на двух языках и отдельная страница кейса в эстетике художественного каталога. После запуска откройте `http://localhost:4173/portfolio/`; английская версия — `http://localhost:4173/portfolio/index.en.html`.

Сохранены глубокий зум, 25 областей, 15 остановок маршрута, 5 нитей символов, поиск, дневник, заметки, RU/EN и источники. Интерпретации не выдаются за окончательную расшифровку каждого символа.

## Быстрый запуск архива

Установите Node.js 22+. В Windows откройте `START_WINDOWS.bat`. На macOS/Linux выполните:

```sh
node scripts/serve.mjs
```

Затем откройте `http://localhost:4173`. Окно терминала оставьте открытым. Для готовой сборки npm-пакеты не нужны; все изображения включены.

## Разработка

```sh
npm ci
npm run dev
```

Проверки и сборка:

```sh
npm test
npm run build
```

## GitHub и обновления

Исходники: [alyalbina/inside-bosch](https://github.com/alyalbina/inside-bosch).

В репозитории находятся исходники, подлинные изображения, документация, лицензии и автоматические проверки. Для разработки клонируйте репозиторий, затем выполните `npm ci` и `npm run dev`. В клонированном репозитории сначала нужна сборка `npm run build`, чтобы использовать `START_WINDOWS.bat` или `scripts/serve.mjs`.

Для повторной публикации сайта в настройках репозитория выберите Pages → Source: GitHub Actions и запустите **Deploy GitHub Pages** во вкладке Actions. [Подробности обновления](docs/PUBLISHING.md).
