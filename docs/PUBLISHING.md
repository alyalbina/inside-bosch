# Deployment and updates

Public source: [alyalbina/inside-bosch](https://github.com/alyalbina/inside-bosch) · default branch `main`.

## GitHub Pages

Choose **Pages → Build and deployment → Source: GitHub Actions** in repository settings. Run **Deploy GitHub Pages** in Actions. The workflow installs dependencies, runs checks, builds and deploys `dist/`.

Relative Vite asset paths support project-page hosting. The deployment includes the application, complete artwork tiles and the editorial case at `portfolio/index.html` and `portfolio/index.en.html`.

For future releases, deploy a reviewed revision by running the Pages workflow. The build checks must pass before publication. The existing ChatGPT review version has its own access settings.

## Local development

```sh
git clone https://github.com/alyalbina/inside-bosch.git
cd inside-bosch
npm ci
npm run dev
```

Before a pull request:

```sh
npm test
npm run build
```

Commit source changes on a branch and open a pull request. Dependencies, build output, internal Site identity and environment files are excluded from Git.
