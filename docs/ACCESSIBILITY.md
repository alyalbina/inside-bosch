# Accessibility requirements and current status

Implemented: semantic header/nav/main/aside; skip link; accessible button names; visible focus; keyboard viewport controls and catalogue alternative; native modal focus trap/Escape/return; localised artwork descriptions and crop descriptions; reduced motion; audio off by default with visible controls; text explanations independent of sound and viewer success.

A viewer canvas is not an equivalent substitute for a full scholarly text edition. The searchable catalogue provides descriptive access to the selected regions, but does not describe every mark of the painting. Native pinch must be verified on touch devices. Colour contrast, screen-reader announcements, focus movement across canvas overlays, reflow at 200/400%, and browser compatibility have not been independently audited.

Required before public accessibility claims: NVDA/Firefox and VoiceOver/Safari walkthroughs, keyboard-only journey, touch/pinch on iOS and Android, reduced-motion verification, contrast measurements, zoom/reflow testing, audio controls and failure-state review. No WCAG compliance certification is claimed.
