# Experience & information architecture

**Wonder → curiosity → looking → comparison → interpretation.** The painting is the primary visual object. Version 0.3 uses a warm paper catalogue spread, rust accents and a dark viewing room; no invented imagery is painted into Bosch’s work.

Opening → Prologue (actual exterior) → Journey (Eden → Garden → Hell) → Epilogue → Free exploration. Header routes expose Symbol Threads, Journal and About/Sources from the opening and exploration screens. A detail inspector accompanies the viewer; the catalogue is also a text-access entry point.

## Narrative sequence

1. **Eden:** encounter, predator, fountain, tiny owl. The apparent calm is questioned through looking.
2. **Garden:** circuit, large birds, enlarged fruit, glass globe, damaged architecture. Repetition and scale change the first impression.
3. **Hell:** burning horizon, ears and knife, Tree-Man, harp, bird-headed creature, pig in a veil. Familiar forms return in different settings.
4. **Epilogue:** compare a museum’s moral reading with the questions raised by close looking. This is not a claim that all possible scholarly positions have been covered.

Free exploration has no score or imposed order. Opening the catalogue or threads does not clear the camera or journal. Choosing a detail from another mode switches to free exploration; the guided journey position remains saved. The journal supplies notes, not achievement badges.

## Responsive intent

Desktop: viewer and independently scrollable inspector; compact route bar below. Tablet: narrower inspector and controls. Below 780 px: viewer above inspector; route controls stay visible near the bottom. These rules are implemented in CSS but visual browser and device QA remain pending.
