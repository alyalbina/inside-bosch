# Inside Bosch — The Garden of Secrets

An early interactive guided investigation of Hieronymus Bosch's **The Garden of Earthly Delights**, based on Museo del Prado descriptions.

## Run
Open `index.html` in a modern browser. **Internet required** for the painting, which is served as a preview from Wikimedia Commons. The image is not bundled into the package.

## Controls
Click **Открыть путешествие**, then use the numbered hotspots or sidebar. Mouse wheel / + − for zoom; drag for pan; **Вся картина** for reset; **Следующее открытие** for tour progression.

## Status & limitations
This is an exploratory prototype, not a complete scholarly edition. Five annotations are included; positions are provisional and need curator/QA review against the displayed image. Deep zoom is limited by one 3840px reproduction request rather than the original 39k source. Exterior triptych leaves, audio, RU/EN, tile server and full catalog are planned. It uses no backend and does not store private data.
